# 验证范围

发布准备时在 Windows、Python 3.11 上验证当前版本：**101 passed，1 skipped**。跳过项为 Windows 符号链接权限不可用。历史版本独立测试：v0.1 4 项、v0.2 6 项、v0.3 14 项通过。

包括：压缩策略与失败保留、Unicode/换行与索引边界、恢复预算、路径保护、损坏回退、项目安装/重复安装/卸载、Hook 子进程协议、doctor、Mock A/B 契约、usage 缓存口径与重复请求、配对一致性、账单证据与质量回退。

固定手动 Hook 模拟验证过响应结构、失败详情、原文字节一致和选择性恢复。该模拟不是 Claude 集成。

用户另行运行的一次真实 Claude 会话中，模型引用了与本地压缩审计精确匹配的专属 Artifact/压缩 ID，支持该次替换内容对模型可见。会话 ID、审计、原日志和机器路径不随公开仓库发布。这不是稳定性或任务费用实验。

离线 Mock 三轮、5 场景、每个场景 2 arm，共 30/30 通过，包含恢复原文。大 Artifact 验证说明：首次索引构建需扫描全文，复用后只读较小索引与目标附近内容；不能将首次成本隐藏，也不保证本地耗时下降。

usage 示例全部是合成数据。导入器可处理明确提供的供应商/网关 usage-only 导出，报告仍注明来源与完整覆盖由调用方声明。缺失数据不按 0 填补，费用估计不能当账单。没有完整真实配对 usage/账单，所以不存在经统计验证的稳定 Token 或费用节省率。

GitHub Actions 矩阵已配置 Windows/Linux、Python 3.10/3.12。远端尚未运行时，不将配置本身称为跨平台验证成功。公开仓库推送后，以 Actions 实际结果为准。
